# Project Guidelines & Baseline Rules

- **Current State is Source of Truth**: Treat the existing codebase as the final baseline version.
- **Strict Content Retention**: Never restore, regenerate, or re-add any previously removed sections, buttons, text, animations, or design elements unless explicitly requested.
- **Targeted Edits Only**: Apply only the exact changes requested in new prompts without altering unrequested sections, layout, or structure.
